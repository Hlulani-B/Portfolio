Nova

An intelligent CSV cleaning pipeline that uses AI to write and execute pandas code, streaming progress live via Server-Sent Events. Type plain English instructions or let the AI automatically clean messy data.

Source Code Live Demo

Overview

Nova is an API that takes a messy CSV, scans it, has an AI write pandas cleaning code, runs that code in a subprocess, re-scans the result, and repeats until the data is clean. Progress, reports, and generated code are streamed live over Server-Sent Events (SSE), giving users real-time visibility into every cleaning step.

It also has a second mode where a person types a plain English instruction (for example "remove rows where age is under 18") and the AI writes and runs code that applies only that change. The AI decides what to fix, but deterministic pandas checks decide when to stop, so the loop cannot be trapped by an opinionated model.

Key Features

Auto-Clean Loop

Automated cleaning pipeline that scans data, generates AI cleaning code, executes it in a subprocess, and re-scans until the data meets quality standards. Maximum rounds configurable to prevent infinite loops.

Instruction Mode

Type plain English instructions like "remove rows where age is under 18" and the AI writes and executes code to apply only that specific change, leaving everything else untouched.

Live SSE Streaming

Real-time progress updates streamed via Server-Sent Events. Watch overviews, scan reports, and generated cleaning code appear live as the AI works through your data.

Multi-Provider AI

Supports both Gemini and Groq AI providers with automatic fallback. If one provider fails or returns bad JSON, the system seamlessly switches to the other.

Subprocess Execution

AI-generated code runs in isolated subprocesses with timeout protection. Scripts read from data.csv and write to cleaned.csv, avoiding command-line length limits.

Safety Nets

Automatic safety code injection fills missing values the AI forgot before assertions run. Hard pandas checks validate results, preventing silent failures from pandas version differences.

How It Works

1. Overview Generation

The system generates a text summary of the CSV: column types, missing value rows, duplicate counts. This overview provides context for the AI about what needs cleaning.

2. AI Scan & Analysis

Pandas profiles the data (shape, dtypes, missing values, duplicates, describe, sample) and sends it to the LLM. The AI returns a JSON response with ok (boolean) and report (markdown explanation of issues found).

3. Code Generation & Execution

If the scan finds problems, the AI writes pandas code to fix them. The code gets a safety net injected, then runs in a subprocess reading data.csv and writing cleaned.csv. Hard checks validate the output before the next round.

4. Instruction Mode (Alternative)

For manual edits, the user types a plain English instruction. The AI writes code to apply only that change, reading with dtype=str to preserve untouched columns exactly. The output is validated against the input to ensure the change did something.

Challenges & Solutions

CORS in GitHub Codespaces

The browser blocked cross-origin API calls from Codespaces. Fixed by adding exact frontend URLs to allow_origins, setting port 8000 to Public, and killing stale uvicorn processes that held the port.

AI Assertion Failures

Generated scripts failed their own assertions when they only filled some columns. Solution: add_safety_net() injects code before assertions to fill every remaining gap with appropriate defaults (median for numbers, Unknown for text, False for booleans).

Pandas Version Conflicts

AI models often write pandas 1/2 code (inplace=True, chained assignment) that silently does nothing in pandas 3. Fixed by pinning pandas 3 rules in every prompt and comparing output to input to detect no-op changes.

Streaming Buffer Issues

Proxies buffered streamed responses until the end, making the frontend appear frozen. Solution: stream starts with a comment line padded with 2048 spaces to force immediate proxy transmission, and frontend normalizes line endings.
