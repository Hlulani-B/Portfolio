Overview

Data preparation is notoriously inefficient. Analysts and engineers face three suboptimal choices: spreadsheets that buckle under large datasets, custom scripts with unnecessary setup overhead, or enterprise ETL platforms with steep licensing costs. Data Cleaner solves this by offering a responsive, browser-based workspace that combines the speed of programmatic cleaning with an intuitive, code-free interface.

Users sign in with Google, upload a CSV or XLSX file, run an automatic initial clean, then apply individual cleaning functions from a library of over 40 utilities. Every operation supports undo, draft history is maintained, and all data persists to Neon Postgres so work is never lost. The platform also features AI-powered chart generation across 11 chart types, with each chart receiving AI-generated titles, axis labels, and plain-English insights about what stands out in the data.

Key Features

Automatic Initial Clean

One-click bundled action: trim whitespace, remove empty rows, eliminate duplicates, and coerce datatypes. Runs once per file and persists the result.

40+ Transformation Functions

Row operations, column manipulation, text case conversion, find and replace, regex extract, date operations, math operations, type conversion, and more.

AI-Powered Visualisation

11 chart types including bar, histogram, pie, scatter, line, area, box plot, violin, heatmap, stacked bar, and bubble charts with AI-generated insights.

Natural Language Search

Describe what you want in plain English (e.g. "remove repetition") and the AI interprets your intent, highlighting the matching function cards.

Undo & Draft History

Revert the last applied operation one step at a time, or jump back to any previous state from saved drafts, most recent first.

Database Persistence

Files are saved to Neon Postgres on upload, synced on every operation, and loaded from the database when revisiting. 15 tables track everything.

Empty Values Inspector

Interactive view with colour-coded table (red for empty cells, yellow for rows with empties), stats dashboard, and batch removal actions.

Real-Time Data Search

Case-insensitive search across all columns simultaneously with highlighted matching cells and a live row count that resets when switching sheets.

Google Authentication

Firebase Google Sign-In protects all routes behind a login screen. New users are automatically registered in Neon Postgres on sign-in.

Architecture

The backend runs on 6 Vercel serverless functions, consolidated to stay within the free tier's 12-function limit. Early in development, each cleaning operation was its own function (18 total), which exceeded the cap. The solution was a unified handler that dispatches based on the operation field, with legacy routes rewritten via vercel.json.

The database schema spans 15 tables: Users, Files, File_Versions, Graphs, plus one dedicated table per chart type. Tables auto-create on first request. The frontend uses React Router with auth guards, and the dev server runs Express with Vite middleware for hot module replacement.

Key Lessons

The Imperative of Automated Testing

Managing dozens of state-mutating functions made manual testing a massive bottleneck. Writing unit tests for pure data functions (243 tests across 22 suites) proved essential for refactoring with confidence, catching boundary edge cases, and preventing regressions.

Serverless Function Consolidation

Vercel's free tier allows 12 functions max. Having 18 individual cleaning operations exceeded this. Consolidating all data transforms into a single unified handler with operation dispatch solved the problem while keeping the API clean through vercel.json rewrites.

Designing for High-Friction Workflows

Real-world data is dirty and unpredictable. Giving users deterministic, instant feedback via live previews and search-by-intent search bars creates a far more reliable experience than relying solely on AI auto-cleaning.
