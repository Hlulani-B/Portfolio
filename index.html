01
Full-Stack Application

Data Cleaner & Visualiser

A fast, browser-based data-cleansing and visualization workspace that bridges the gap between fragile spreadsheets and tedious custom scripts. Users can upload CSV or XLSX files, run an automatic initial clean, then apply over 40 individual cleaning functions with undo, draft history, and Neon database persistence. The platform features AI-powered chart generation with 11 chart types, real-time data search, and a natural-language function search bar where users describe what they want in plain English.

Built to solve the real problem of data preparation inefficiency, this project combines the speed of programmatic cleaning with an intuitive, code-free interface. It supports Google Sign-In via Firebase, serverless backend functions on Vercel, and persistent storage on Neon Postgres with 15 database tables tracking users, files, versions, and chart data.

02
AI-Powered Platform

Rihanyo

A multi-agent, AI-powered appointment booking assistant that connects patients with medical practices through natural conversation. Practices can register and manage appointment requests while an AI admin filter screens incoming requests for relevance before they reach a human. The platform includes a chatbot receptionist that greets visitors, answers common questions, and routes or books appointment requests automatically.

Built entirely on free-tier services as a solo student project, Rihanyo uses a fallback chain across five AI providers (Cerebras, OpenRouter, Hugging Face, Groq, Gemini) so if one runs dry the system quietly moves to the next. It features location-based practice search, Firebase hosting on Cloud Functions, and Gmail API integration for notifications.

03
Microservices Architecture

Digital Logbook

A microservices-based digital logbook application built with a React frontend and four independent Node.js/Express backend services, each running on its own port. The architecture includes an Auth Service for login and signup via Supabase, a Dashboard Service for cross-project summaries and search, a Project Service for entries, timelines, and AI-powered features, and a Profile Service for user profiles and preferences.

The system uses Supabase for authentication and PostgreSQL database management, with CI/CD pipelines that auto-generate test coverage badges. Each service follows strict architecture rules: project entries stay scoped to their service while the dashboard only shows cross-project summaries. All four backend services are deployed live on Render.

04
AI Productivity Tool

E-Draft

An AI-powered email drafting assistant with a premium, Canva-inspired interface. Type a prompt, get a fully drafted email, and send it directly through your authenticated Gmail account. The app uses an open-source LLM (gpt-oss-20b via Groq) for instantly rephrasing, formalizing, or writing emails from scratch.

Built with React and Vite on the frontend, Firebase Google Sign-In for frictionless one-click authentication, and the Gmail API using OAuth 2.0 access tokens captured at login. Emails send directly through Gmail's REST protocol with proper base64url encoding. The interface features Plus Jakarta Sans and Inter font pairing with responsive input fields and active focus states.

05
AI Productivity Tool

Cortex

A serverless full-stack app that transforms hours of video and audio lectures into clean, structured markdown notes. Drop in an audio or video file, or paste a YouTube link directly, and Cortex uses Gemini 2.5 Flash to generate organized notes from the content. The notes get rendered into a styled PDF you can preview right in the browser or download.

Built with React and Vite, Cortex handles MP3, WAV, MP4, and MOV uploads with a 55-minute duration limit to stay within the model's token constraints. Larger media files go through the Gemini File API using resumable upload. YouTube integration uses the YouTube Data API v3 to fetch video duration. The layout uses Archivo Black and Inter fonts with fully responsive styling.

06
AI Health Application

Derma

An AI-powered skin analysis and product recommender that examines your skin in real time through your webcam. Take a photo straight from your browser using WebRTC, and the image gets analysed by Google Gemini 2.5 Flash Lite, which determines your skin type, main concerns, and which ingredients would actually help. It then generates personalised skincare formulation recommendations based on that analysis.

The app searches for real products matching those recommendations and pulls in product images using Cheerio HTML parsing, so you see actual products rather than just a text list. The backend runs on Node.js with the AI and vision work handled by Gemini's lightweight model.

07
Local-First Task Manager

Dira

A quiet place to keep track of what needs doing. Add a task, tick it off, move on with your day. A single-user, local-first task manager built with Next.js 16, React 19, and better-sqlite3. There are no accounts and nothing is deployed anywhere. You clone the repo, run it, and your tasks are stored in a SQLite file on your own machine.

Tasks can be tagged with colour-coded topics (Grocery, Assignments, Work, Health, Projects), move through a three-status workflow (Todo, In Progress, Complete), and are archived rather than deleted. The app features computed overdue status, TypeScript type safety, Tailwind CSS styling, and a Jest test suite that runs against a throwaway database to never touch real data.
