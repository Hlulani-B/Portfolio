Full-Stack Safety Platform

SOS App

The cloud-backed evolution of Safe, disguised as a plain weather app. Ordinary city chips hide one-tap triggers: Johannesburg starts video, Durban starts audio, Cape Town sends an alert with live location — the colour of a small dot is the only label, and a red chip is the only visible state. A second screen plots trusted contacts (pals) sharing their live positions on a South-Africa-bounded map, each resolved to a real street address with the current weather there.

The frontend is React 19 + Vite and deliberately router-less: a localStorage view state machine means the address bar never hints at what the app is, and the live-location share loop lives in a module-level singleton so it survives navigation and page refreshes. The backend is Express 5 on Neon Postgres behind a generic, allowlisted function dispatcher, with Firebase handling only Google sign-in. Deployed as two Render services (API + static web) via a render.yaml blueprint.
