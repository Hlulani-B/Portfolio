Full-Stack Attendance Platform

Kopano (Church)

A check-in and community app for small church fellowships. A leader opens a session at the front of the room, everyone else marks themselves present from their phone with a four-digit PIN or a QR code, and the register writes one row per person per gathering. Between those two moments sit the parts that make it safe: a time window, a haversine distance rule, a nullable cancel column that behaves like a one-way switch, and a service-role key that never leaves the server.

The React 19 SPA and a separate /qr subapp talk to three Vercel serverless tiers (/api/self, /api/leader, /api/admin) that verify the Firebase ID token on every request and refuse anything outside their allowlisted function map before the role gate is even consulted. The Supabase layer runs on PostgREST with RLS on the four tables that need it, and the twelve-page MkDocs Material documentation site walks through the architecture, the honest security gaps still open, and every probe that was run against live data.
